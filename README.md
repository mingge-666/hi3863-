# hi3863- 环境监测巡检机器人

基于 **Hi3863** 的环境监测巡检机器人项目。  
通过传感器采集环境数据，在 OLED 上本地显示，并计划通过 **华为云 IoTDA（MQTT）** 上传到云端，实现远程监控与命令下发。

---

## 项目简介

本项目以 Hi3863 为主控，做一个轻量级环境监测 / 巡检终端：

- 采集环境数据：温湿度、可燃气体浓度
- 本地显示：0.96 寸 OLED
- 运行模式切换：通过 UART 通信切换不同工作模式
- 异常报警：环境参数超阈值时触发报警
- 云端控制：华为云下发命令，控制 GPIO 高低电平
- 后续目标：传感器数据稳定上报华为云，形成完整巡检系统

## 工作原理

1. Hi3863 上电后初始化 Wi-Fi、I2C、UART、GPIO、传感器
2. 通过 UART 接收指令，切换“平地模式 / 上楼梯模式 / 下楼梯模式/危险模式”
3. 定时读取：
   - 温度、湿度
   - 可燃气体浓度
4. OLED 实时显示采集结果
5. 若温度 / 气体浓度超过阈值：
   - 蜂鸣器报警
   - LED 报警
   - 可上报告警状态
6. 连接华为云 IoTDA：
   - 设备上报属性
   - 平台下发命令
   - Hi3863 解析命令并控制 GPIO 输出高/低电平

## 华为云接入说明

使用 **MQTT + JSON** 接入华为云 IoTDA。

### 1. 华为云配置

- 创建产品：协议类型 `MQTT`，数据格式 `JSON`
- 添加服务
- - 注册设备，获取：
  - `device_id`
  - `device_secret`
- 使用华为云工具生成：
  - `client_id`
  - `username`
  - `password`
- 填写到 `wifi_05_mqtt` 中的 MQTT 配置位置

### 2. 平台下发命令
设备收到后：

- `level = 1` → GPIO 输出高电平
- `level = 0` → GPIO 输出低电平

## 快速使用

### 本地功能

1. 烧录 `my_program`
2. 串口观察日志
3. 通过 UART 发送模式切换指令
4. OLED 显示温湿度 / 可燃气体
5. 超阈值时报警

### 上云功能

1. 在华为云创建产品和设备
2. 修改 `wifi_05_mqtt` 中的：
   - `WIFI_SSID`
   - `WIFI_PASSWORD`
   - `MQTT_ADDRESS`
   - `CLIENT_ID`
   - `USERNAME`
   - `PASSWORD`
3. 编译并烧录
4. 华为云设备状态变为“在线”
5. 查看属性上报 / 下发命令控制 GPIO
